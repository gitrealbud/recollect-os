# Loops

**What this is for:** checkable exits and matching process to stakes — not more gates.

**Plain-first:** day-one surfaces use everyday English only — *claim → load little → propose → you accept → stop*. Formal names below are for precision in this kit. Glossary: [`LAW.md`](./LAW.md). Companion: [`RESEARCH-AND-ANALYSIS.md`](./RESEARCH-AND-ANALYSIS.md). Refusals: [`ANTI-GOALS.md`](./ANTI-GOALS.md).

Exit-first work loops.

## What these loops optimize for

1. Kill/success checkable in under a minute when possible.
2. One live status home + one question per surface — lower navigation tax.
3. Stop-conditions and verifiers beat longer chains.
4. Minimum viable process ≠ no process. Keep stakes, ask-first writes, anti-re-exploration; subtract duplicate sources of truth.
5. Feedback shape: claim → minimal load → act/propose → exit test → purge. Escalate only when stakes demand.
6. **Evidence vs decision.** Evidence note first; main-note summary only after a fixed bar is met.

## Default vs Elevated

### DEFAULT — routine / known path

```text
claim + stakes
  → compressed cold-load / Attach
  → act or single draft (propose)
  → exit test
  → closure
  → purge
  → optional one-line process note
```

**Skip by default:** perspective pass, full research audit, diagnostic scorecards — unless the claim requires them.

### ELEVATED — net-new / critical / architecture / evidence work

```text
claim + stakes
  → Structure (goal, constraints, Done when, Kill when)
  → If evidence gap: Research loop
       lock question + Done when
       source bar → findings → contradictions
       write evidence leaf (verdict · findings · non-claims)
  → If operating residue required: Analysis loop
       generate → pure evaluate (grounding · contradiction · actionability · density · scope)
       PASS only → hub residue; else refine or HOLD
  → execute one phase
  → verify
  → next phase or stop
  → closure
  → purge
```

**Do not** merge research and analysis into one summary dump.  
**Do not** paste research bodies into the hub.

### Defaults (usually)

- One live status home when status is in play (Now section for the endeavor; optional personal focus — don’t copy the same fact)
- Stop-conditions named before multi-step or cross-window work
- No invented quality-gate events
- No second full plan when a phase edit will do
- Routine tasks don’t pad with extra diagnostics — see [`ANTI-GOALS.md`](./ANTI-GOALS.md)
- Before external synthesis: check existing trails (anti-re-exploration)
- Prefer **net-new area** wording — not “domain” — when elevating beyond frontmatter `personal`/`business`

## Stop-conditions (first-class)

Before multi-step work, write two lines:

```text
Done when: <checkable success>
Kill when: <checkable abort>
```

Optional third:

```text
Hold when: <park without failure>
```

Put the same lines on handoffs (see `templates/handoff.md`).

## Scaffold budget

| Expected durable write | Preference |
|------------------------|------------|
| ≤2 files | Prefer a **single** artifact unless operator asks to split |
| Larger system change | Phase the approach; one phase → verify → next |

Scaffold size tracks expected durable write size. Do not build a multi-doc operating system for a two-line markdown fix.

## Efficiency levers

- Reuse locked structure
- Pointers over pasted live tables
- Exit test before research
- Skip diagnostics on routine claims
- Compress research/analysis on routine; never skip the bar on elevated evidence claims

## Quality levers (keep)

- Ask-first irreversible writes
- Anti-re-exploration
- Kill criteria for *this* run
- Agreement at finalized elevated gates
- Pure evaluate on analysis (judge only)
- Private metrics ≠ proof of practice — [`ANTI-GOALS.md`](./ANTI-GOALS.md)

## Kill criteria for “tightening”

Tightening fails if it:

- Removes agreement on critical work
- Drops anti-re-exploration
- Substitutes synthetic drill claims for lived claims
- Turns unsupervised auto-mode into the default
- Merges research trails into hub bodies as a substitute for evaluate

## Success test

- Next routine claim completes without perspective/research unless triggered.
- Next elevated evidence claim locks question + Done when before search.
- Next analysis write only after PASS on the fixed bar.
- Scaffold size tracks durable write size.

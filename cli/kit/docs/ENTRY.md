# Entry

**If you open one file for “how do I work here?” — this is it.**

```text
notes   →  your vault (Markdown on disk)
rules   →  LAW.md · WRITE-CLASSES.md   (filenames only — just rules + write gate)
install →  START-GUIDE.md
connect →  ATTACH.md · examples/attach/
prove   →  DEMO.md
```

This package is a **small practice kit**, not an “OS” or constitution.

## First hour

| Do | Open |
|----|------|
| Install vault | [START-GUIDE.md](./START-GUIDE.md) |
| Three ideas | Disk record · load little · draft then accept |
| Connect agent (or CLI only) | [ATTACH.md](./ATTACH.md) |
| One Inbox note or `status` | your vault |
| Rules when stuck | [LAW.md](./LAW.md) · [WRITE-CLASSES.md](./WRITE-CLASSES.md) |

**Stop when:** vault exists, you know draft→accept, and you either attached a host or chose CLI-only.

## Doors

| Need | Open |
|------|------|
| Install / smoke | START-GUIDE |
| Connect agent | ATTACH · mcp README |
| When may the agent write? | WRITE-CLASSES (write gate) |
| Full rules | LAW (rules file) |
| 60s prove | DEMO |

**Never:** chat as the record · same live fact in two homes · Secrets in public faces.

# Write classes

**What this is for:** durable edits stay reviewable. Class the write so tools (and humans) know whether to proceed, draft, ask, or refuse apply.

**Plain-first:** day-one surfaces (README, DEMO, Card, CLI/MCP messages) use everyday English only — *draft needs accept · ask first · not allowed by tools*. Formal names below are for precision in this kit. Glossary: [`LAW.md`](./LAW.md). Scope refusals: [`ANTI-GOALS.md`](./ANTI-GOALS.md).

| Class | Everyday meaning | When |
|-------|------------------|------|
| **Auto** | safe (auto) | Reversible / protocol micro-ops — tools may proceed |
| **Propose** | draft (needs accept) | Agent drafts; human accepts before apply |
| **Human-gate** | ask first | Irreversible or sensitivity-bearing — ask before write |
| **Forbidden** | not allowed by tools | Tools will not apply; not “try carefully” |

| Class | Industry gloss | Examples |
|-------|----------------|----------|
| **Auto** | tool-safe / reversible | Fill missing `created`; append today’s daily when asked; normalize required frontmatter; overwrite Scratch |
| **Propose** | HITL draft | Inbox filing; promotions to evergreen; new business hubs; personal focus priority changes |
| **Human-gate** | ask before write | Delete; bulk archive; domain flip; merges; cross-domain copies; restricted bulk; public publish; durable **Me** / **Preferences** / identity edges |
| **Forbidden** | tools won’t apply | Invent facts; curiosity reopen; dual-home the same live fact; fake quality gates; free-string `rel` (see RELATIONSHIP-SCHEMA) |

Proposal should name original `domain` + `sensitivity` — not a professional cover story.

## Claim gate

Before editing a hot path:

1. State the **claim** (one unit of work).
2. Name paths you will touch.
3. Name explicit denials.
4. Prefer one claim pack per session — complete exit, then stop. *(Claim pack ≠ research pack.)*

## Propose vs apply (two steps)

- **Propose** and **apply** stay separate for weekly review and bulk vault reshape — so durable edits are reviewable.
- “Looks good in chat” is not apply authority unless the operator said apply.
- Public portfolio / client drafts should not auto-export restricted notes.

## Restricted hygiene

- Restricted person notes require a body banner marking restricted status.
- Do not bulk-load restricted notes into client, portfolio, or public export context.
- Semantic cover (reframing restricted topics as “career research”) raises sensitivity, not lowers it.

## Optional session surfaces

If you keep a thin session strip for agent work:

| Surface | Write rate | Rule |
|---------|------------|------|
| Personal focus | low | Personal operating strip only |
| Hub | low | Pointers + Now section |
| Scratch | very high | Overwrite-OK; purge at claim end |

Open research-pack leaves **only when the claim names them**.

## Closure write

At claim end, prefer:

1. Checkable done/kill result
2. Promote durable crumbs to canonical homes
3. Purge or interrupt-resume Scratch
4. Optional one-line process note — no transcript dump

# Write gate

**What this is for:** durable edits stay reviewable. Filename `WRITE-CLASSES.md` is historical.

## Three outcomes

| Outcome | Meaning |
|---------|---------|
| **Safe micro-ops** | Reversible housekeeping — tools may proceed without a click each time |
| **Draft → accept** | Durable note edits are proposed; you accept before they stick |
| **Tools refuse** | Some paths never apply (not “try carefully”) |

That is the whole model. Rules overview: [`LAW.md`](./LAW.md).

## When which applies

| When | Stance | Examples |
|------|--------|----------|
| Reversible housekeeping | Safe micro-ops | Fill missing `created`; append today’s daily when asked; normalize required frontmatter; overwrite scratch |
| Durable note change | Draft → accept | Inbox filing; promotions to evergreen; new business hubs; personal focus priority changes |
| Irreversible or sensitive | Ask first | Delete; bulk archive; domain flip; merges; cross-domain copies; public publish; durable Me / Preferences / identity edges |
| Never through tools | Tools refuse | Invent facts; same live fact in two places; restricted bodies; Secrets/Archive paths; free-string relationship labels; auto-sync private→public |

Wire values in MCP/CLI (same meanings, for machines only): `Auto` · `Propose` · `Human-gate` · `Forbidden`.

### Friction (honest)

**Not every keystroke needs accept.** Low-stakes reversible work is safe micro-ops so high-volume loops don’t need a click each time.

**Inbox is a hold pen.** New captures may land and sit until hygiene. Promote out of Inbox = draft for accept when you care.

**Chat → notes:** If you ask the agent to synthesize or remember for the system, it should **file a note** (often Inbox) and point you at the path — not only leave an essay in chat.

**Draft → accept is for durable notes** — evergreen, “what’s true now,” business hubs, priority changes — where silent agent write is the failure mode. If a workflow feels too slow, re-class work as safe micro-ops or Inbox hold before abandoning the gate.

High-volume *durable* spam still needs accept (or redesign so it is not durable).

Proposal should name original `domain` + `sensitivity` — not a professional cover story.

## Before you edit a hot path

1. State the **task** (one unit of work).  
2. Name paths you will touch.  
3. Name explicit denials.  
4. Prefer one task pack per session — complete exit, then stop.

## Draft vs apply (two steps)

- Draft and apply stay separate for weekly review and bulk reshape — so durable edits are reviewable.  
- “Looks good in chat” is not apply authority unless the human said apply.  
- Public portfolio / client drafts should not auto-export restricted notes.

## Restricted hygiene

- Restricted person notes require a body banner marking restricted status.  
- Do not bulk-load restricted notes into client, portfolio, or public export context.  
- Semantic cover (reframing restricted topics as “career research”) raises sensitivity, not lowers it.

## Optional session surfaces

| Surface | Write rate | Rule |
|---------|------------|------|
| Personal focus | low | Personal operating strip only |
| Main note | low | Pointers + “what’s true now” |
| Scratch | very high | Overwrite-OK; purge at task end |

Open research detail notes **only when the task names them**.

## At task end

1. Checkable done/stop result  
2. Promote durable crumbs to their one home  
3. Purge or park scratch  
4. Optional one-line process note — no transcript dump

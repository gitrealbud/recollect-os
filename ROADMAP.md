# Roadmap

**Ready to use.**  
Notes on disk are the record. Load little — short index, at most two notes. Nothing permanent until you accept. Local MCP home for agents.

Run the [60-second DEMO](./docs/DEMO.md). That is the system.

Language reference: [docs/TAXONOMY.md](./docs/TAXONOMY.md).

---

## Coming down the pipe

Work stays inside the same three rules. Nothing here removes the rails. The agent can carry more continuity load inside those rails; you still accept permanent writes.

### Active vs archived notes

- **Active** — main notes that currently answer “what’s true now.” These stay on the short index.
- **Archived** — still in the vault, findable by name, off the default index.

Scaling without a second live surface or automatic decay.

### First workflows

Thin session patterns, not unconstrained agents:

- **Continuity open** — at session start, surface the “what’s true now” section of active main notes only, as a plain list, then stop  
- **Weekly hygiene** — review short index, flag stale status, draft archive moves; human accepts  
- **Claim intake** — name the task, draft main note, accept, stop  

(Continuity open and weekly hygiene are the first uses of higher agency inside the rails.)

### Not on this path

Automatic memory, vector/graph layers as source of truth, background rewrites, or agents that skip acceptance.

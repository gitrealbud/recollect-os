# recollect-os

Local tools and a small practice for agents that work against a markdown vault.  
Your notes stay private. This package is the shared practice kit.

**Current:** MCP `0.4.5-overlay` · CLI `0.3.7`

---

## Quick Start

```bash
npx -y recollect-os init ~/recollect
```

Push the folder to a **private** GitHub repository — that is your durable source of truth.

1. **Local MCP** — attach a host at your machine ([docs/ATTACH.md](./docs/ATTACH.md))  
2. **HTTP** (optional) — live tools away from the machine; accept stays local  
3. **Work** — agent drafts durable changes; you accept before they stick  

Prove it: [docs/DEMO.md](./docs/DEMO.md)

---

## Three ideas

1. **Notes on disk are the record** — not the chat  
2. **Load little** — short index, at most two notes  
3. **Nothing permanent until you accept**
